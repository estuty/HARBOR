How it works

  1. Connect a repository and branch. Private repositories use a deploy key that Harbor creates for this site.
  2. Deploy: Harbor fetches the branch, runs your build as {{ site.sysuser }}, then copies the result into the live folder. If the build fails, the live site isn't touched.
  3. Push to deploy: add the webhook to GitHub, GitLab, Gitea or Bitbucket and every push to the branch goes live.
  4. Roll back to any earlier deploy with one click.

The first deploy replaces what's in the site folder, so Harbor backs up the current files and databases first. Disk use: the repository copy is kept in git/ next to the site's files.
